# Versión 2.3.0 — Respuestas preestablecidas por integración

**Fecha**: 2026-09-01

## Resumen

Las respuestas preestablecidas del chat dejan de vivir en Clarify y ahora se consultan desde cada integración, para que se vea con claridad qué responde cada sitio conectado.

## Novedades

- **Respuestas dentro de Integraciones**: En Configuración → Integraciones, cada integración con agente asignado tiene un botón que despliega las respuestas preestablecidas que usa ese chat. Desde ahí se pueden regenerar con el agente o eliminarlas, igual que antes.
- **Vista por integración**: La lista ya no mezcla las respuestas de todos los agentes; se ve únicamente lo que corresponde a la integración que se está revisando.

## Notas

- La pestaña "Respuestas" desapareció de la pantalla de Clarify. El contenido es el mismo, solo cambió de lugar.
- Los permisos siguen siendo los mismos: hace falta acceso a respuestas preestablecidas para ver el panel, y permiso de actualizar o eliminar para cada acción.
