# Versión 1.15.0 — Varios providers de LLM y selección del activo

**Fecha**: 2026-06-30

## Resumen

Ahora puedes configurar más de un provider de modelo de lenguaje y elegir cuál usa el agente, ya sea mediante el inicio de sesión de OpenAI (Codex) o mediante una API compatible con OpenAI.

## Novedades

- **Varios providers a la vez**: En *Configuración → Providers* puedes registrar tantos providers por API como necesites, además del de OpenAI (Codex). Cada uno guarda su nombre, dirección (Base URL), clave y modelo.
- **Provider activo**: Marca con un clic cuál provider debe usar el agente. La selección manda sobre la configuración por variables de entorno, así que puedes cambiar de modelo sin reiniciar el servicio.
- **Providers por API**: Agrega cualquier servicio compatible con OpenAI (por ejemplo, Azure OpenAI u otros endpoints) indicando su Base URL, clave de API y modelo por defecto.
- **Gestión más clara**: La pantalla muestra el estado de cada provider (conectado, requiere refresco, activo) y permite eliminarlos individualmente.

## Notas

- Las claves de API y los tokens se almacenan cifrados en la base de datos.
- Si no marcas ningún provider como activo, el agente sigue funcionando como antes, usando la configuración por variables de entorno.
- El provider de OpenAI (Codex) mantiene su mismo flujo de conexión, validación y refresco automático.
