# Versión 1.7.0 — Monitoreo de recursos del servidor

**Fecha**: 2026-06-03

## Resumen

Ahora puedes ver en tiempo real cuánta CPU y memoria está usando el servidor donde corre la aplicación, directamente desde la pantalla de Configuración.

## Novedades

- **Pestaña "Recursos" en Configuración**: Una nueva pestaña muestra el uso de CPU y de memoria del servidor, junto con el consumo de memoria del propio proceso, el tiempo que lleva activo y datos del equipo (nombre, plataforma y carga del sistema).
- **Actualización automática**: Las métricas se refrescan cada 5 segundos. Puedes pausar o reanudar la actualización automática, o forzar una actualización manual cuando lo necesites.
- **Indicadores visuales**: Las barras de uso cambian de color (verde, ámbar y rojo) para que identifiques de un vistazo cuándo el servidor está bajo presión.
- **Gráfica histórica en el tiempo**: Una gráfica de líneas muestra la evolución del uso de CPU y memoria conforme se toman las muestras, para que puedas detectar tendencias y picos sin quedarte mirando un solo valor.

## Notas

- La pestaña solo es visible para usuarios con permiso de lectura sobre el nuevo recurso "Métricas del sistema". Tras actualizar, ejecuta la siembra de permisos (`npm run db:seed`) para que el rol administrador (y los roles de solo lectura) reciban este acceso.
