# Versión 2.2.0 — Elegir el modelo y el nivel de razonamiento de Codex

**Fecha**: 2026-08-28

## Resumen

Ya no hace falta tocar variables de entorno ni reiniciar el servidor para cambiar el modelo de OpenAI (Codex): ahora se elige desde la pantalla de Providers y aplica de inmediato a todo lo que usa el agente.

## Novedades

- **Selector de modelo en Providers**: la tarjeta de OpenAI (Codex) muestra la lista de modelos que tu cuenta tiene disponibles, consultada directamente a OpenAI. Junto a cada modelo se ve su descripción y su ventana de contexto.
- **Nivel de razonamiento configurable**: para el modelo elegido puedes seleccionar cuánto debe "pensar" antes de responder. Las opciones que aparecen son exactamente las que ese modelo admite, con una breve explicación de cada una. Si cambias de modelo y el nivel anterior no existe en el nuevo, se ajusta solo al recomendado.
- **Se aplica en todas partes**: el modelo y el nivel guardados se usan en el chat, los agentes, los webhooks, las integraciones y las tareas programadas. La variable `AGENT_MODEL` queda únicamente como respaldo para cuando no hay nada elegido.
- **Auditoría más fiel**: el consumo de tokens y las bitácoras registran el modelo que realmente se usó en cada ejecución, no el configurado en el arranque.

## Notas

- El catálogo de modelos se refresca automáticamente cada 8 horas; el botón "Recargar catálogo" fuerza la consulta cuando OpenAI publica un modelo nuevo.
- Para ver la lista es necesario tener la conexión con ChatGPT activa. Si el token expiró, primero usa "Validar / refrescar".
- Los providers configurados por API siguen definiendo su modelo a mano; esta versión no cambia su comportamiento.
