# Versión 1.9.0 — Módulo Clarify: proyectos y documentos

**Fecha**: 2026-06-11

## Resumen

Nueva sección "Clarify" para explorar la base de conocimiento: ahora puedes ver todos los proyectos y documentos registrados, y subir nuevos documentos sin salir de Agent Manager.

## Novedades

- **Catálogo de proyectos**: consulta todos los proyectos de documentación disponibles, agrupados por área, con su descripción y estado.
- **Listado de documentos**: revisa los documentos registrados con su tipo (PDF, HTML, enlace), estado de procesamiento, categorías y fecha de creación, con buscador integrado.
- **Subida de documentos**: carga un archivo desde tu equipo, asígnale un título y al menos una categoría, y quedará registrado y procesado automáticamente en la base de conocimiento.

## Notas

- El acceso a la nueva sección se controla con el permiso `clarify` (ver / subir). Los roles existentes deben recibir el permiso desde Admin → Roles; el rol admin lo obtiene automáticamente al ejecutar el seed.
