# Versión 1.9.0 — Webhooks

**Fecha**: 2026-06-12

## Resumen

Ahora puedes crear webhooks desde Configuración: direcciones web propias del sistema que, al ser invocadas por otras aplicaciones, ejecutan automáticamente un agente o una herramienta MCP.

## Novedades

- **Nueva pestaña "Webhooks" en Configuración**: Crea, edita, activa/desactiva y elimina webhooks desde una sola pantalla. Cada webhook muestra su dirección completa lista para copiar.
- **Vinculación con agentes o herramientas**: Al crear un webhook eliges su destino: un agente (que recibirá los datos enviados y actuará sobre ellos) o una herramienta de un servidor MCP (que se ejecutará con esos datos como parámetros).
- **Método HTTP configurable**: Tú decides cómo se invoca cada webhook (GET, POST, PUT, PATCH o DELETE). Las llamadas con un método distinto al configurado son rechazadas.
- **Autenticación opcional con token secreto**: Puedes proteger cada webhook con un token que se genera automáticamente. Quien invoque el webhook deberá enviarlo en el encabezado `X-Webhook-Secret`. El token se puede ver y copiar desde la lista de webhooks. Si prefieres un webhook abierto, basta con desactivar la opción.
- **Respuesta inmediata**: El webhook confirma la recepción al instante y la ejecución del agente o herramienta continúa en segundo plano, sin hacer esperar al sistema que lo invocó.

## Notas

- Se agregaron los permisos `webhooks` (crear, ver, actualizar, eliminar). Tras actualizar, ejecuta el seed de permisos (`npm run db:seed`) y asigna los permisos a los roles que deban administrar webhooks.
- Los webhooks desactivados responden como inexistentes ante quien los invoque.
