# Versión 1.14.0 — Endpoints HTTP de salida

**Fecha**: 2026-06-25

## Resumen

Ahora puedes registrar endpoints HTTP externos y hacer que la plataforma los llame enviándoles datos, ya sea cuando tú lo decidas o de forma automática según un horario.

## Novedades

- **Registro de endpoints externos**: En *Configuración → Endpoints* puedes dar de alta servicios externos indicando su URL, método (GET, POST, PUT, PATCH, DELETE), cabeceras y el cuerpo de datos que se enviará.
- **Autenticación flexible**: Cada endpoint puede llamar al servicio externo sin autenticación, con un token Bearer, con una API Key en una cabecera, o con cabeceras personalizadas para cualquier otro esquema.
- **Ejecución manual con vista de respuesta**: Pulsa "Ejecutar" para llamar el endpoint al instante. Puedes ajustar el cuerpo de la petición antes de enviarla y ver de inmediato el código de estado y la respuesta del servicio.
- **Ejecución programada (cron)**: Opcionalmente puedes asignar una expresión cron para que el endpoint se llame de forma automática y periódica. La plataforma recuerda estos horarios incluso tras reiniciarse.
- **Historial de la última corrida**: Cada endpoint muestra el resultado de su última ejecución (estado y fecha), tanto para corridas manuales como programadas.

## Notas

- La gestión de endpoints respeta los permisos del rol: se requieren los permisos del recurso `http_endpoints` (crear, ver, actualizar/ejecutar, eliminar). Ejecuta la siembra de permisos para que el rol administrador los obtenga.
- Esta función es de salida (la plataforma llama hacia afuera) y complementa a los Webhooks, que son de entrada (sistemas externos llaman a la plataforma).
