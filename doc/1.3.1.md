# Versión 1.3.1 — La lista de herramientas de un MCP siempre actualizada

**Fecha**: 2026-05-26

## Resumen

Corrección puntual para que el panel de herramientas de un servidor MCP refleje siempre las herramientas vigentes del servidor remoto.

## Correcciones

- **Herramientas siempre al día**: Al abrir el panel de herramientas de un servidor MCP, la lista ahora se consulta en vivo y muestra los cambios del servidor remoto (herramientas agregadas o eliminadas) sin necesidad de reiniciar la aplicación. Antes podía quedarse mostrando una lista antigua.

## Notas

- El cambio aplica a los servidores MCP externos. Los servidores locales no se ven afectados.
