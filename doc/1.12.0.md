# Versión 1.12.0 — El asistente vive en otros sitios

**Fecha**: 2026-06-18

## Resumen

Ahora puedes incrustar el asistente de chat en sitios web externos con un solo fragmento de código. Aparece como un botón flotante que abre una ventana de chat, y funciona igual que el asistente público de conocimiento.

## Novedades

- **Asistente embebible**: con una línea de código (un `<script>`), cualquier sitio externo muestra un botón de chat flotante que, al presionarlo, abre una ventana de conversación. La experiencia es la misma que la del asistente público: respuestas en tiempo real, preguntas frecuentes y sugerencias mientras escribes.
- **Registro automático de sitios**: la primera vez que un sitio nuevo usa el asistente, queda registrado automáticamente como "pendiente". No hace falta darlo de alta a mano antes de probar.
- **Administración desde Configuración**: en **Configuración → Integraciones** puedes ver todos los sitios, asignarles el agente que debe atenderlos, definir qué datos acompañan cada conversación (nombre, correo, teléfono, estar logueado) y activarlos. Cada sitio trae su fragmento de código listo para copiar.
- **Cada sitio con su propio asistente**: distintos sitios pueden usar distintos agentes y configuraciones; el asistente reconoce de qué sitio proviene cada conversación.
- **Tema claro u oscuro**: puedes elegir el aspecto del asistente al incrustarlo (`?theme=am-dark` o `data-theme`) o cambiarlo en vivo desde tu sitio con `window.IntegrationWidget.setTheme(...)`. Si no defines nada, sigue la preferencia del visitante.

## Notas

- Mientras un sitio esté "pendiente" (sin agente asignado o desactivado), el chat mostrará un aviso de que aún no está disponible. En cuanto le asignes un agente y lo actives, empezará a responder.
- Se agregó el permiso `integrations` (crear, ver, actualizar, eliminar). Tras actualizar, ejecuta `npm run db:seed` y asígnalo a los roles que deban administrar las integraciones.
- El asistente se identifica por el **origen** (dominio) del sitio que lo incrusta; por eso cada sitio debe configurarse por separado.
