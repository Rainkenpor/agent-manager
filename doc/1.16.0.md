# Versión 1.16.0 — Webhooks con destino LLM (estilo OpenAI)

**Fecha**: 2026-06-30

## Resumen

Ahora un webhook puede exponer directamente el LLM de agent-manager con un contrato compatible con OpenAI Chat Completions, convirtiéndolo en un endpoint que sistemas externos pueden consumir como si fuera un proveedor de chat.

## Novedades

- **Nuevo destino "LLM" en Webhooks**: al crear o editar un webhook ahora puedes elegir, además de "Agente" y "Tool MCP", el destino **LLM**. Este responde en el momento (no en segundo plano) con el resultado del modelo, en el mismo formato que usa OpenAI para el chat.
- **System prompt configurable**: cada webhook LLM puede tener sus propias instrucciones, que se anteponen a cada solicitud que reciba.
- **Tools asignables al LLM**: igual que a un agente, puedes seleccionar del catálogo qué herramientas puede usar el LLM en este webhook. agent-manager las ejecuta automáticamente y devuelve la respuesta final ya resuelta.
- **Respuesta inmediata o en streaming**: el webhook LLM admite respuestas completas o incrementales (streaming), según lo pida quien lo consume.
- **Compatible con clientes/SDK de OpenAI**: puedes apuntar un cliente estilo OpenAI a la URL del webhook (usando el secret como API key) y funcionará sin cambios adicionales.

## Notas

- El modelo lo determina el proveedor activo configurado en agent-manager; el modelo que indique quien llama al webhook se ignora.
- Los webhooks existentes con destino "Agente" o "Tool MCP" no cambian su comportamiento.
- En esta versión, las herramientas que use el LLM son las asignadas en la configuración del webhook; las que envíe el cliente en la solicitud no se toman en cuenta.
