# Versión 1.11.0 — El asistente público aprende

**Fecha**: 2026-06-15

## Resumen

El asistente de conocimiento público ahora recuerda lo que ya respondió: las preguntas frecuentes se contestan al instante sin volver a consultar a la IA, se sugieren preguntas mientras escribes y todo se administra desde Clarify.

## Novedades

- **Respuestas instantáneas a preguntas frecuentes**: cuando alguien hace una consulta nueva, el asistente la responde y guarda automáticamente esa respuesta junto con varias formas de preguntar lo mismo. La próxima vez que alguien pregunte algo equivalente, recibe la respuesta de inmediato.
- **Sugerencias mientras escribes**: al teclear tu consulta en el chat público aparecen preguntas frecuentes relacionadas; al elegir una obtienes la respuesta al momento.
- **Privacidad por diseño**: lo que se guarda se reformula en términos generales. Se eliminan nombres, direcciones, fechas y datos que puedan identificar o señalar a personas; los casos puramente personales no se guardan.
- **Nuevo apartado "Respuestas" en Clarify**: permite ver el listado de preguntas y respuestas guardadas, **actualizar** una respuesta (el asistente la regenera) y **eliminar** las que ya no apliquen.

## Notas

- Se agregó el permiso `preset_qna` (ver, actualizar, eliminar). Tras actualizar, ejecuta `npm run db:seed` y asígnalo a los roles que deban administrar estas respuestas.
- La detección de preguntas similares se basa en coincidencia de texto; mientras más se usa el asistente, mejor cubre las variantes.
- Si una respuesta guardada quedó desactualizada, usa "Actualizar" para regenerarla con el asistente, o elimínala para que vuelva a responder la IA.
