# Versión 1.10.0 — Asistente público de conocimiento

**Fecha**: 2026-06-15

## Resumen

Ahora cualquier persona puede conversar con el asistente de conocimiento de Distelsa desde una página web pública, sin necesidad de iniciar sesión ni tener una cuenta.

## Novedades

- **Chat abierto a todos**: Una nueva página accesible en la dirección `/conocimiento-distelsa` permite chatear directamente con el asistente. Está pensada para compartirse con cualquier persona dentro o fuera de la organización.
- **Sin inicio de sesión**: No se pide usuario ni contraseña. Al abrir la página se inicia automáticamente una conversación lista para usarse.
- **Conversación enfocada**: La página solo trabaja con el asistente de conocimiento, sin menús ni selección de agentes, para una experiencia simple y directa.
- **Respuestas en vivo**: Las respuestas se muestran a medida que se generan, con soporte para texto enriquecido, tablas y diagramas.
- **Botón "Nuevo chat"**: Permite empezar una conversación desde cero en cualquier momento.

## Notas

- Cada visita inicia una conversación nueva; el historial no se conserva al recargar la página.
- La página requiere que exista un asistente activo identificado como `conocimiento-distelsa`. Si no está disponible, se muestra un aviso al visitante.
- No se requieren cambios de permisos ni de base de datos para esta versión.
