# Versión 2.4.0 — Enlaces en el widget del asistente

**Fecha**: 2026-09-02

## Resumen

El asistente embebido en sitios externos ahora puede compartir enlaces y estos se muestran como links en los que se puede hacer clic.

## Novedades

- **Enlaces clicables en el widget**: cuando el asistente menciona una página (un portal, un documento, un formulario), el enlace aparece subrayado y se abre en una pestaña nueva sin salir del sitio donde está el widget. Funciona tanto con enlaces con texto ("ver la guía") como con direcciones escritas tal cual.

## Correcciones

- Las direcciones web largas ya no se recortan con asteriscos al mostrarse en el widget.

## Notas

- Solo se convierten en enlaces las direcciones `http` y `https`; cualquier otro tipo de dirección se muestra como texto.
